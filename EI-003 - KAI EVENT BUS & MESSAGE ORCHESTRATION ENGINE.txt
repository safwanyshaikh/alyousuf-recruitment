LOVABLE RULES
============================================================

Every enterprise event must use the centralized Event Bus.

Every event schema must remain version controlled.

Every subscriber must remain independently deployable.

Every event automatically generates Timeline and Audit records.

No production workflow may depend on direct synchronous integration when event-driven execution is feasible.
