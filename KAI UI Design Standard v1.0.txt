============================================================
PURPOSE
============================================================

This document is the single implementation standard for every
screen, module, workspace, dashboard, table, drawer, component,
interaction and workflow inside KAI.

The Constitutions define WHY.

The UI Design Standard defines HOW.

Every future implementation inside Lovable, Claude Code,
Codex, Cursor or any development team shall follow this
document.

============================================================
KAI UI PHILOSOPHY
============================================================

KAI is NOT

• ATS
• CRM
• ERP
• HRMS
• Candidate Database
• Dashboard Software

KAI IS

A Workforce Intelligence Operating System.

Recruiters should comfortably spend an entire working day
inside KAI without depending on

• Excel
• Personal Notes
• WhatsApp Lists
• Separate Follow-up Diaries
• Manual Registers
• Personal Candidate Lists

Except where external clients or government authorities require
their own formats.
