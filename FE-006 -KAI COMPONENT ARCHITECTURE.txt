============================================================
PURPOSE
============================================================

Create one universal Component Architecture for the entire KAI
Operating System.

Every UI element must originate from reusable enterprise components.

No duplicated components.

No business logic inside components.

============================================================

============================================================

↓

============================================================
LOVABLE RULES
============================================================

Every component must belong to the Design Library.

Never duplicate components.

Never place business logic inside components.

Every component must be reusable across all modules.

Every component must support accessibility, responsiveness,
performance optimization and design tokens by default.
