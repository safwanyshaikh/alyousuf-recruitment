============================================================
LOVABLE RULES
============================================================

Never call APIs directly from components.

Every API request must pass through Feature Services.

Every response must be normalized.

Every failure must preserve UI state.

All mutations must automatically refresh Timeline, Queue,
Notifications and Dashboard through TanStack Query.

Never duplicate API logic across modules.
