LOVABLE RULES
============================================================

Every API request must pass through the Platform API Gateway.

No service is directly exposed to external consumers.

Every request must be authenticated, authorized and validated.

Every API interaction automatically generates Timeline and Audit records.

Gateway policies must remain centralized, versioned and independently deployable.
