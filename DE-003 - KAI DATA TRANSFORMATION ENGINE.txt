LOVABLE RULES
============================================================

Every transformation must be deterministic and reproducible.

Raw data must never be modified.

Every transformation rule must be version controlled.

Every transformed dataset automatically generates Metadata, Lineage, Timeline and Audit records.

No transformed data reaches downstream systems without passing quality validation.
