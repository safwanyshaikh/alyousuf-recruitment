============================================================
LOVABLE RULES
============================================================

Operational database and Search Index remain independent.

Every business change automatically updates the Search Index.

Search Index is eventually consistent.

Never execute business logic inside Search.

Every indexed entity supports Natural Language Search, AI Search,
Vector Search, Timeline Search and Cross-Entity Search.
