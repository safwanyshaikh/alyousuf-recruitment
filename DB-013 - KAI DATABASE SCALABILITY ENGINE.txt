LOVABLE RULES
============================================================

Every database design must support horizontal scaling.

No table may assume single-server execution.

Every large dataset must support partitioning and archival.

Every service must tolerate replica failover without application changes.

Scalability decisions must preserve performance, integrity,
security and auditability.
