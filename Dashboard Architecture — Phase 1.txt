# 🔒 KAI UI LOCK

# Dashboard Architecture — Phase 1

---

# Principle

Dashboards are not reports.

Dashboards exist to help people make decisions within seconds.

Every widget must answer one operational question.

If a widget cannot change today's decision, it does not belong on the dashboard.

---

# Dashboard Types

```
Management Dashboard

Recruiter Dashboard
```

Both use the same data.

Both answer different questions.

---
