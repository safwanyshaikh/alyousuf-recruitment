============================================================
PURPOSE
============================================================

Create one universal Repository & Data Access Layer for the entire
KAI Workforce Intelligence Operating System.

Repositories persist data.

Repositories never execute business rules.

Repositories never orchestrate workflows.

============================================================
LOVABLE RULES
============================================================

Repositories persist only.

Never place business rules inside repositories.

Never access repositories directly from controllers.

Always access through Application Services.

Every repository must support pagination, filtering, sorting,
soft delete, optimistic locking and audit metadata.
