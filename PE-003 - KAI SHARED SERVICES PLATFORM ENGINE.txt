============================================================
LOVABLE RULES
============================================================

Every shared capability must exist only once across the platform.

Applications must consume shared platform services rather than implement duplicate logic.

Every shared service must expose health checks, metrics and audit events.

Breaking API changes are prohibited without version upgrades.

Every platform service interaction automatically generates Timeline and Audit records.
