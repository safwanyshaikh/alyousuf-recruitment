# KAI OS CONSTITUTION 015

# RECRUITER CONSTITUTION

## Recruiters Recruit. KAI Handles Everything Else.

**Status:** DRAFT v1.0

---

# PURPOSE

The Recruiter Constitution defines how recruiters work inside KAI.

It protects recruiters from administration.

It protects recruiters from duplicate work.

It protects recruiters from remembering information that software should remember.

Recruiters are employed to recruit.

Not to maintain systems.

---

# RECRUITER PHILOSOPHY

Recruiters create

Relationships

Trust

Communication

Evaluation

Negotiation

Placements

Software creates

Memory

Structure

Tracking

Reminders

Consistency

Organisation

KAI exists so recruiters spend maximum time speaking to people.

Not typing.


Recruiters never restart planning.

They continue working.

# RECRUITER VALIDATION

Every future recruiter feature must answer

1.

Does this reduce recruiter workload?

2.

Does this increase communication time?

3.

Does this reduce administration?

4.

Does this preserve organisational intelligence?

5.

Can recruiters complete the work without leaving KAI?

6.

Does this reduce dependency on Excel?

7.

Would an experienced GCC recruiter naturally adopt this workflow?

If any answer is NO,

the feature shall be redesigned.
