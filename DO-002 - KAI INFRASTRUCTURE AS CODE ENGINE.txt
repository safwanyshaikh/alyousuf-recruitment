LOVABLE RULES
============================================================

Every infrastructure resource must originate from version-controlled code.

Manual production changes are prohibited.

Every infrastructure change requires validation, approval and rollback capability.

Configuration drift must be automatically detected.

Every infrastructure deployment generates Timeline and Audit records.
