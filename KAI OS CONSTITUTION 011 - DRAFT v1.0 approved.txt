# KAI OS CONSTITUTION 011

# SEARCH CONSTITUTION

## Recruiters Search For People. KAI Finds Everything.

**Status:** DRAFT v1.0

---

# PURPOSE

Search is not a feature.

Search is the primary operating system inside KAI.

A recruiter should never remember

where information is stored.

The recruiter only remembers

what they know.

KAI is responsible for finding everything else.
